# 弹弹堂 3：弹王宝典日常录制助手

目标站点：<http://ddt.wan.com/>。在 **Windows 本机**、已登录的浏览器游戏画面上，通过图像识别重放操作。按弹王宝典从上到下录制，每次点击先找按钮，再等待操作后的稳定标记出现。

**当前提供可运行的录制/重放工具，没有附带已经验证的弹王宝典任务流程。** 云环境无法访问该站（代理返回 403），也没有登录后的任务画面，因此没有虚构任务名称、按钮坐标或宣称可自动通关。首次需在实际游戏中录制和验证。战斗中的瞄准、力度计算和动态副本策略尚未实现，不能用固定点击流程保证完成这类任务。

本项目独立实现，未复制第三方源码。[DDTankAuto](https://github.com/Tziheng/DDTankAuto) 针对 Windows 微信小程序版新弹弹堂，它的识别图和流程不能直接用于这个页游。

## 安装

下载代码包后先解压，安装 Windows Python 3.12（包含 Python Launcher），再双击 `start.bat`。它会准备依赖并显示菜单：`1` 录制、`2` 执行、`3` 检查、`4` 退出。首次仍需录制游戏流程；不要直接在压缩包内运行。批处理入口尚未经 Windows 实机验证。

安装 Windows 的 Python **3.12**（含 pip 和 Tcl/Tk），在项目目录用 PowerShell 执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m ddt_daily --help
```

不需要账号密码、Cookie 或其他凭据。直接使用你现有能玩游戏的浏览器，手动登录、选区服和角色。仅支持主显示器，录制后保持游戏位置、窗口尺寸、浏览器缩放和 Windows 显示缩放一致。

## 第一次：按宝典顺序录制

先打开弹王宝典，作为以后每次执行的起始画面。把终端移到游戏区域外，再执行：

```powershell
.\.venv\Scripts\python.exe -m ddt_daily record
```

1. 按提示切回游戏，框选整个游戏区域。静态截图窗口中拖框，回车确认，Esc 取消。
2. 按宝典从上到下为步骤命名，例如 `任务一/前往`、`任务一/领取`、`任务一/回宝典`。这些只是命名示例，工具不预设真实任务列表。
3. 选择按钮的识别框。**框中心会被实际点击一次**；选择按钮本体，包含稳定的图标或文字，避开倒计时、玩家名、动画背景。每次倒计时都要将游戏切到前台。
4. 等点击后的界面稳定，回终端按回车，再切回游戏。框选一个**点击后才出现**的标记，例如弹窗标题、已领取状态。结束标记不能在点击前已经存在。
5. 每项任务结束，录制回到宝典及该任务完成标记的步骤，再录下一项。需要额外等待时，选择 `w` 类型，框选应当出现的画面。
6. 步骤名称留空结束。已有配置再次 `record` 会追加；重新开始请换 `--profile`，不会覆盖旧流程。

画面不变的按钮（例如长按蓄力、连续点击战斗区）不适合此录制器。结束条件应能证明这一步成功。若录制中取消或出错，此前已保存的步骤仍保留，当前步骤不会进入流程；点击可能已经实际发生，重录前应手动恢复游戏状态。

默认前台窗口标题须包含 `弹弹堂`。若浏览器实际标题不同，首次录制时使用 `record --window-title "实际标题的一段文字"`。不要使用过于通用的窗口标题。

## 每天执行

```powershell
.\.venv\Scripts\python.exe -m ddt_daily check
.\.venv\Scripts\python.exe -m ddt_daily run --max-minutes 15
```

`check` 仅检查配置和模板文件；`run` 才会操作桌面。启动有 5 秒时间让你切回已登录、处于录制起始画面的游戏。先在可重复、无消费的步骤上验证图像识别，然后再扩展日常流程。

识别范围限定在游戏区域内、录制位置附近默认 40 像素。匹配失败、多个相似目标、窗口失焦、屏幕尺寸变化或超时都会停止。按住 **Esc**、将鼠标移到主屏幕角落，或在终端按 Ctrl+C 可中止。仅在所有步骤的结束标记均确认后才记为完成；这是录制流程完成记录，不能独立证明宝典所有任务均已完成。

同一配置每天成功后不再重复执行，日期按 `Asia/Shanghai` 计算（游戏流程配置，可自行修改）；该日期设置不代表已核实服务器日常重置时间。若失败、中断或当天修改了流程，会阻止直接重试，以避免重复执行。先检查游戏状态、恢复起始画面，再明确重跑：

```powershell
.\.venv\Scripts\python.exe -m ddt_daily run --force
```

每个角色用独立配置：`python -m ddt_daily --profile role1 record`，执行时也加 `--profile role1`。不要对同一配置同时运行多个进程。失败截图在 `runs/`，识别图片、配置及每日记录在 `profiles/`；均已被 Git 忽略，只保留在本机。

若要每天定时运行，可在 Windows 任务计划程序创建每日任务：选择“仅当用户登录时运行”，程序选项目下 `.venv\Scripts\python.exe`，参数为 `-m ddt_daily run`，起始目录设为本项目绝对路径，并禁止任务重叠。仍需让电脑保持解锁、浏览器已登录、游戏处于起始画面。当前未实现无人值守登录、断线重连或将执行中的游戏恢复到起始页面；不满足条件会停止。

## 开发验证

图像匹配及流程执行测试可在 Linux 运行，不依赖真实桌面：

```console
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

这些测试验证匹配、状态记录和停止条件，不代替 Windows 实机及游戏内验证。
